# NYCU Computer Security | Spring 2025

A portfolio of four projects from the Computer Security course at National Yang Ming Chiao Tung University (NYCU) in Spring 2025 (academic year 113, semester 2). The projects cover TLS connection hijacking, MITM and pharming attacks in Wi-Fi networks, ransomware propagation and payloads, and capture-the-flag challenges.

## Projects

| Project | Topic | Objective |
| --- | --- | --- |
| 1 | TLS Connection Hijacking | Implement a Python program to demonstrate TLS connection hijacking in the course-provided VM environment. |
| 2 | MITM and Pharming Attacks in Wi-Fi Networks | Implement C/C++ programs for ICMP redirect and DNS spoofing experiments in the course-provided VM environment. |
| 3 | Ransomware Propagation and Payload | Implement the propagation and file-encryption components of a ransomware lab in the course-provided Docker environment. |
| 4 | Capture The Flag (CTF) | Analyze seven CTF challenges and write programs that automatically retrieve their flags. |

Project 2 includes only the assignment specification because the implementation files are no longer available.

## Lab environment

> Run coursework programs only inside an isolated virtual machine (VM) or Docker container. Keep the lab environment off production and shared networks.

## How to use this portfolio

Read each project specification, then explore the corresponding implementation and lab resources. Follow the course's distribution and submission rules for the original lab materials.
